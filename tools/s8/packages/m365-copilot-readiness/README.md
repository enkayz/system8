# M365 Copilot Readiness

Creates an evidence-backed pilot gate from live licensing, site lifecycle, public collaboration and guest signals while explicitly identifying permission evidence that Graph cannot prove.

```powershell
s8 install m365-copilot-readiness
s8copilot full -InstallDependencies -StaleDays 365
```

This is a planning assessment, not a security guarantee. Complete SharePoint Advanced Management/Purview permission and oversharing reviews before production rollout.
